Use Pkg for create backend

1. Core backend packages
npm install express mongoose dotenv cors helmet

express — backend REST API

mongoose — MongoDB connection and models

dotenv — environment variables/secrets

cors — frontend/backend communication

helmet — HTTP security headers

2. Authentication & security
npm install bcrypt jsonwebtoken otplib

bcrypt — securely hash passwords

jsonwebtoken — authentication tokens, if using JWT

otplib — TOTP/OTP-based MFA

For your requirements, bcrypt + TOTP is a suitable implementation for a lab project.

3. Validation
npm install zod

Use zod to validate things such as:

Login request
Registration request
MFA verification
Role changes
Password changes

4. Logging
npm install pino pino-http

These can help you record backend events without putting passwords or MFA secrets into logs.

5. Development packages
npm install -D nodemon

Then your package.json can have:

{
  "scripts": {
    "dev": "nodemon src/server.js",
    "start": "node src/server.js"
  }
}

npm install express mongoose dotenv cors helmet bcrypt jsonwebtoken otplib zod pino pino-http

The first step is to define the schemas cleanly, with security requirements such as no plaintext passwords, protected MFA secrets, RBAC, auditability, and timestamps.

1. User.js
import mongoose from "mongoose";

const userSchema = new mongoose.Schema(
  {
    username: {
      type: String,
      required: true,
      unique: true,
      trim: true,
      minlength: 3,
      maxlength: 50,
    },

    email: {
      type: String,
      required: true,
      unique: true,
      lowercase: true,
      trim: true,
    },

    role: {
      type: mongoose.Schema.Types.ObjectId,
      ref: "Role",
      required: true,
    },

    status: {
      type: String,
      enum: ["active", "locked", "disabled"],
      default: "active",
    },

    lastLoginAt: {
      type: Date,
      default: null,
    },
  },
  {
    timestamps: true,
  }
);

export default mongoose.model("User", userSchema);
